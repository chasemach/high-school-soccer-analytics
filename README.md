# High School Soccer Analytics

A data-driven soccer analytics project built from event-level match data
collected from a high school soccer team during the 2026 season.

## Project Overview

I developed a custom match-event tracking system to collect structured
soccer data during live matches. The system records player actions,
locations, outcomes, and contextual information that can later be used
for statistical analysis and predictive modeling.

## Data Collection

The tracker records events including:

- Passes
- Shots
- Dribbles/Carries
- Crosses
- Tackles
- Interceptions
- Clearances
- Saves
- Fouls
- Corners
- Throw-ins
- Goal kicks

Shot events additionally include:

- Shot location
- Body part
- Shot type
- Assist type
- Defensive pressure
- Outcome

## Planned Analysis

The project will eventually be used to develop:

- Player performance statistics
- Per-90 statistics
- Shot maps
- Passing networks
- Expected Goals (xG)
- Player match ratings
- Player combination analysis
- Team performance trends
